## 1. 프로젝트 개요



본 프로젝트는 ****AI 기반 1차 채용면접 자동화 플랫폼****을 기획하고 구현하는 것을 목표로 합니다. 지원자의 채용공고 확인 및 지원부터 AI 면접, 코딩테스트, 자동 평가, 결과 확인까지의 과정을 하나의 서비스로 구성합니다.



공통 문서는 팀원 간 논의를 통해 작성하며, ****프로그램은 각 팀원이 공통 문서를 참고해 개별적으로 구현****합니다. 기술 스택과 구현 방식은 개인별로 달라질 수 있습니다. 공통 문서 작성은 동일한 코드나 단일 프로그램의 공동 개발을 의미하지 않습니다.



### 1.1. 프로젝트 진행 원칙



\- ****문서 작성:**** 팀원 간 논의를 통해 공통으로 진행합니다.

\- ****프로그램 구현:**** 공통 문서를 참고하여 각 팀원이 개별적으로 구현합니다.

\- ****구현 방식:**** 개인별 기술 선택과 구현 방식은 달라질 수 있습니다.

\- ****문서 활용:**** 공통 문서는 개발 기준 및 참고 자료입니다.

\- ****피드백 반영:**** 피드백노트에 의견을 기록하고 검토 후 문서에 반영합니다.

\- ****버전 관리:**** GitHub에서 변경 사항을 관리하고 README 및 관련 문서에 주요 변경 내역을 기록합니다.

#### AI 아키텍처 — 작성·업로드 완료 / 검토 진행

AI 면접 시스템에 필요한 LLM, RAG, STT·TTS, 영상·음성 분석 등의 AI 역할과 처리 파이프라인 및 시스템 연동 구조를 정리한 문서입니다. 파일관리대장에는 완료로 기록되어 있으며, 최신 버전 번호는 별도 확인이 필요합니다.

**2026년 10월 30일 회의 반영 사항**

- Qwen, BGE-M3, Whisper 등은 검토 대상이며, 모델 성능과 개인별 개발 환경이 달라 특정 모델을 공통 필수 사양으로 확정하지 않았습니다.
- AI 처리 흐름과 파이프라인 구조를 공유하되 모델 선택은 개별 구현자에게 맡깁니다.
- LangChain과 LangGraph를 논의했으며, 복잡한 처리 흐름의 구현에는 LangGraph를 우선 고려하기로 의견을 모았습니다.
- RAG 관련 추가 의견은 추후 확인하기로 했으며 확정된 설계 변경 사항은 아닙니다.
- 문서 검토 절차: 성준 작성 → 진희 검토·수정본 반영 → 성준 승인 → 팀원 공유. 실제 최종 승인 여부는 별도 확인이 필요합니다.

### 2.5. 문서 간 정합성 검토 사항

| STT 최종 실패 | 동일 질문 재시도 또는 장애 중단·재접속 정책 |

## 3. 문서 관리 및 업무 현황



### 3.1. 파일관리대장 (Document Register)



프로젝트 문서의 ****목록, 디렉토리별 분류, 저장 위치, 담당 역할, 마감기한, 작성·수정 상태****를 관리합니다. 문서 누락과 중복 작성을 방지하고 팀원들이 필요한 문서를 찾도록 지원합니다.



### 3.2. WBS 업무관리 (Work Breakdown Structure)



담당자별 업무 범위, 예정 시작·마감일, 실제 시작·완료일, 진행 상태와 지연 여부를 관리합니다. 팀원들은 작업 상태를 지속적으로 갱신하고 후속 작업 및 전체 일정을 공유합니다.



### 3.3. 회의록 (Meeting Minutes)



회의에서 제시된 의견, 합의된 결정, 누락·보완 사항, 후속 논의 주제를 기록합니다. PRD·TRD 등 설계 문서의 결정 근거로 활용합니다. 최신 회의록은 **2026년 10월 30일 AI 아키텍처 회의**이며, 모델 선택 자율성, LangGraph 활용 의견, 구현 착수, 검토·배포 절차가 포함됩니다.



### 3.4. 피드백노트 (Feedback Notes)



문서의 오류·누락·불명확한 내용, 기능·기술 개선 의견, 추가 검토 사항과 반영 여부를 기록합니다. ****문서 검토 → 피드백 기록 → 수정 여부 논의 → 문서 보완****의 흐름으로 운영합니다.



### 3.5. 문서별 역할 구분



| 문서 | 핵심 목적 | 확인 사항 |

|---|---|---|

| 파일관리대장 | 문서·담당 역할 관리 | 어떤 문서가 있고 누가 언제까지 작성하는가? |

| WBS 업무관리 | 업무·일정 관리 | 누가 어떤 작업을 맡았고 어디까지 진행했는가? |

| 회의록 | 논의·결정 관리 | 무엇을 논의·결정하고 무엇을 보완해야 하는가? |

| 피드백노트 | 검토·개선 관리 | 어떤 문제·개선 의견이 있으며 무엇을 수정해야 하는가? |



****논의 → 업무 수행 → 문서 작성 → 피드백 → 문서 개선 및 관리****로 연결합니다. 회의 결정은 필요시 WBS에 반영하고, 산출물은 파일관리대장에 등록하며, 검토 의견은 피드백노트로 관리합니다.
