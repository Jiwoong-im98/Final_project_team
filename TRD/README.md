## TRD (기술 요구사항 정의서)

**문서명:** AI 1차 채용면접 자동화 플랫폼 TRD  
**파일명:** `Final_Project_TRD_v1.2.pdf`  
**버전:** v1.2  
**최종 작성일:** 2026년 10월 28일  
**진행 상태:** 초안 (Draft) / 일부 기술 검증 및 팀 협의 필요  
**기준 문서:** 통합 PRD v1.3

### 문서 개요

본 문서는 AI 기반 1차 채용면접 자동화 플랫폼의 기술 요구사항을 정의한 문서입니다.

통합 PRD v1.3에서 정의한 주요 기능과 운영 정책을 실제 시스템으로 구현하기 위해 필요한 기술 스택, 시스템 아키텍처, 데이터 구조, API 인터페이스 및 AI 모델 운영 방식을 구체화하였습니다.

특히 제한된 하드웨어 환경에서 AI 면접과 코딩테스트, 자동 평가 및 합격·불합격 판정을 안정적으로 수행할 수 있도록 **기술적 실현 가능성과 시스템 운영 효율성**을 고려하여 설계하였습니다.

### 주요 작성 내용

- **시스템 아키텍처:** Next.js, FastAPI, Celery 기반 서비스 구성 및 Docker Compose 배포 구조
- **기술 스택 정의:** Python, TypeScript, PostgreSQL, Redis, MinIO 및 AI 모델 운영 환경
- **데이터 설계:** 사용자, 채용공고, 지원서, 질문은행, 면접 답변, 평가 결과 및 운영 설정 데이터 구조
- **API 및 실시간 통신:** REST API, WebSocket 기반 면접 진행, 상태 관리 및 실시간 이벤트 처리
- **AI 모델 배치:** VRAM 6GB·RAM 58GB 환경을 고려한 실시간 LLM, 평가 LLM, STT, TTS 및 임베딩 모델 구성
- **AI 면접 파이프라인:** 질문은행 적재, 질문 검색·생성, 꼬리질문 판단, 답변 처리 및 이력서 OCR
- **AI 평가 및 판정:** 루브릭 기반 평가, 점수 계산, AI 합격·불합격 판정 및 결과 검증
- **코딩테스트 실행 환경:** Docker 격리 실행, 리소스 제한, 자동 저장 및 테스트케이스 기반 채점
- **장애 및 예외 처리:** 네트워크 단절, 장치 오류, 서버 장애, 화면 이탈 및 면접 재접속 처리
- **보안 및 개인정보:** 접근 권한 검증, 데이터 암호화, 보관 기간 관리 및 자동 삭제
- **성능 및 테스트:** 시스템 응답 시간, 동시 면접 처리량, 모델 성능 측정 및 인수 테스트
- **운영 설정 관리:** 재시도 횟수, 타임아웃, 동시 면접 상한 등 주요 설정값 관리

### v1.2 주요 변경 사항

- 통합 PRD v1.3에서 이관된 기술 구현 세부사항 반영
- 네트워크 및 시스템 장애 감지 신호와 판정 기준 구체화
- 질문은행 데이터 적재 방식과 질문 선정·중복 제거 규칙 정리
- AI 평가 결과의 하이라이트 구간 산출 방식 추가
- 결과 공개 시각, 데이터 삭제 예정일 및 관리자 알림 처리 기준 정리
- 로그인 이후 복귀 경로 검증 및 보안 처리 보완
- 동시 면접 상한 관리와 초과 시 재시도 방식 제안
- 운영 환경과 개발 환경을 구분한 설정값 관리 표 추가
- PRD 요구사항과 기술 구현 및 테스트 항목 간 추적 관계 보완

### 문서 활용 방향

본 TRD는 프로젝트의 **공통 기술 설계 및 구현 기준 문서**로 활용합니다.

PRD에서 정의한 기능을 구현하기 위한 기술적 방향을 제시하며, 향후 API 명세서, ERD, 테이블 정의서, 테스트 계획서 및 실제 프로그램 개발 과정에서 참고 자료로 사용합니다.

각 팀원은 공통 기술 요구사항을 참고하여 개별적으로 프로그램 구현을 진행하며, 구현 과정에서 발생하는 기술적 문제와 성능상의 제약을 확인하고 개선 방향을 검토합니다.

또한 실제 개발 환경과 운영 장비에서 성능 검증을 진행하여 기술 선택의 적합성을 판단하고, 필요한 경우 팀원 간 협의를 통해 기술 요구사항을 보완할 예정입니다.

※ 본 문서는 v1.2 초안 기준이며, AI 모델 배치 방식과 동시 면접 처리 상한 등 일부 항목은 실제 운영 장비에서의 성능 측정 및 팀원 협의를 거쳐 최종 확정할 예정입니다.
