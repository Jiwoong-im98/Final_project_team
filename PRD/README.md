## PRD (제품 요구사항 정의서)

**문서명:** AI 1차 채용면접 자동화 플랫폼 통합 PRD  
**파일명:** `Final_Project_PRD_v1.6.pdf`  
**버전:** v1.6  
**최종 작성일:** 2026년 10월 29일  
**진행 상태:** 작성 완료 (Baseline / TRD v1.5 검토 사항 반영)

### 문서 개요

본 문서는 **AI 기반 1차 채용면접 자동화 플랫폼의 제품 요구사항을 정의한 문서**입니다.

팀원별로 작성한 PRD를 통합하고, 회의 및 피드백을 통해 주요 기능과 운영 정책을 구체화하였습니다.

AI가 면접 진행부터 평가·채점, 1차 합격·불합격 판정까지 수행하고, 관리자는 결과와 평가 근거를 확인하는 시스템을 목표로 합니다.

특히 **사용자 관점에서 제품이 제공해야 할 기능과 동작, 평가 기준, 예외 상황 및 운영 정책을 명확하게 정의**하는 데 중점을 두었습니다.

### 주요 작성 내용

- **프로젝트 목표 및 범위:** AI/AX 엔지니어 직무를 대상으로 한 1차 채용면접 자동화 및 서비스 성공 지표 정의
- **사용자 및 관리자 기능:** 채용공고 등록, 지원, 이력서 제출, 면접 응시, 결과 확인 및 관리자 운영 기능
- **AI 면접 진행:** 질문은행 기반 질문 구성, 이력서 기반 질문 생성, 꼬리질문, STT·TTS 및 실시간 답변 자막
- **코딩테스트:** Python 기반 코딩테스트 출제, 격리 환경에서의 코드 실행 및 자동 채점
- **AI 평가 및 판정:** 고정 루브릭과 평가 가중치를 활용한 점수 산출, 평가 근거 기록 및 AI의 1차 합격·불합격 판정
- **예외 상황 처리:** 네트워크·시스템 장애, 브라우저 종료, 화면 이탈, 응시 중단 및 이어가기 정책
- **질문 생성 및 대체:** 질문 생성 실패 시 재시도, 예비 질문 대체 및 질문 구성 기준
- **데이터 및 보안 정책:** 온프레미스 AI 처리, 접근 권한 관리, 개인정보 보호 및 데이터 보관·삭제 기준
- **인수 기준:** 요구사항별 기능 검증, 평가 결과 확인, 장애 복구 및 데이터 처리 기준 정의

### v1.6 주요 변경 사항

- TRD v1.5 검토 및 결정 사항을 반영하여 PRD와 기술 설계 간 정합성 개선
- 다음 질문 출력 시간, 일반 화면 응답 시간 및 꼬리질문 판단 시간 등 성능 관련 세부 기준을 TRD 14장으로 이관
- 네트워크 연결이 끊긴 시점에 장애 여부를 판단하도록 처리 기준 변경
- 지원자가 브라우저 창을 닫은 경우 응시를 종료하도록 정책 명확화
- 화면 이탈 1회 발생 시 경고 후 동일 질문의 남은 답변 시간부터 이어서 진행하도록 변경
- 질문별 사전 채점 시작 시점을 해당 질문의 응답 종료 이후로 명확화
- '대기'를 별도의 응시 상태가 아닌 사용자 안내 화면으로 구분
- AI의 1차 합격·불합격 판정에 대해 시스템은 형식·점수 범위·근거를 검증하고, 별도 점수 규칙으로 재판정하지 않도록 역할 명확화
- AI 면접 진행 중 지원자의 답변을 실시간 자막으로 표시하는 기능 추가
- 별도 운영 서버 대신 팀원 PC 중 기준 PC를 활용하며, 서비스 접속 범위를 로컬 환경(`127.0.0.1`)으로 구체화

### 문서 활용 방향

본 PRD는 프로젝트의 **공통 제품 요구사항 기준 문서**로 활용합니다.

향후 기능정의서, 시나리오 기획서, 화면정의서, API 명세서, 데이터베이스 설계 및 테스트 계획서 작성 시 참고하며, 세부 기술 구현 방식은 TRD v1.5를 기준으로 검토합니다.

각 팀원은 공통 요구사항을 참고하여 개별적으로 프로그램 구현을 진행할 수 있으며, 구현 과정에서 발견된 문제점과 개선 의견은 피드백노트를 통해 관리하고 필요시 문서를 보완합니다.

또한 요구사항별 식별 ID를 활용하여 **PRD·TRD·API 명세서·테스트 문서 간의 연관성을 관리**하고, 구현 과정에서 요구사항의 누락이나 불일치가 발생하지 않도록 검토합니다.

※ 본 문서는 v1.6 기준으로 작성되었으며, TRD v1.5 검토 사항을 반영한 확정본입니다. 단, 일부 추천 정책과 공고의 차별 표현 감지 방식 등은 팀원 간 추가 확인이 필요합니다.
