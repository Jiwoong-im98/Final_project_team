## 화면정의서 (Screen Specification)

**문서명:** AI 1차 채용면접 자동화 플랫폼 화면정의서  
**파일명:** `Final_Project_화면정의서_v0.3.md`  
**버전:** v0.3  
**최종 작성일:** 2026년 10월 28일  
**진행 상태:** 초안 (Draft) / 일부 화면 정책 및 기술 연계 사항 검토 필요  
**기준 문서:** 통합 PRD v1.3 · 서비스 플로우차트 07v · TRD v1.2

### 문서 개요

본 문서는 AI 기반 1차 채용면접 자동화 플랫폼의 사용자 및 관리자 화면 구성과 동작 방식을 정의한 문서입니다.

통합 PRD v1.3, 서비스 플로우차트 07v, TRD v1.2를 기반으로 각 기능을 실제 화면 단위로 구체화하였으며, 화면별 와이어프레임, 구성 요소, 버튼 동작, 화면 전환 조건, API 연계 및 예외 처리 방식을 정리하였습니다.

v0.3에서는 기존 화면 설계를 보완하여 **응시 상태에 따른 접근 제어, 지원 환경 제한, 화면 이탈 처리, 코딩테스트 타이머 관리 및 관리자 공고 수정 정책**을 구체화하였습니다.

이를 통해 프론트엔드와 백엔드 개발 과정에서 발생할 수 있는 기능 해석의 차이를 줄이고, 예외 상황에서도 일관된 사용자 경험을 제공하는 것을 목적으로 합니다.

### 주요 작성 내용

- **화면 구조 및 정보 설계(IA):** 사이트맵, 화면 ID, URL 라우트, 사용자별 접근 권한 및 상태별 라우트 가드
- **화면 전환 규칙:** 지원자·관리자별 화면 이동, 버튼 클릭, 자동 전환 조건 및 응시 상태별 처리
- **공통 UI 규칙:** 레이아웃, 디자인 토큰, 버튼, 상태 배지, 알림, 모달, 오류 및 빈 상태 처리
- **인증 화면:** 로그인, 회원가입, 비밀번호 재설정 및 관리자 초기 비밀번호 변경
- **지원자 화면:** 공고 탐색, 필수 동의, 이력서 제출·OCR, 환경 점검 및 면접 시작 안내
- **AI 면접 화면:** 질문 준비, 음성 질문·답변, 녹화, 실시간 연결 상태 및 화면 이탈 관리
- **코딩테스트 화면:** 시험 안내, 코드 작성, 자동 저장, 서버 기준 타이머 및 최종 제출
- **응시 예외 처리:** 네트워크 장애, 화면 이탈, 음성 인식 실패, 동시 면접 상한 초과 및 접수 마감
- **마이페이지:** 지원 내역, 응시 상태, 면접 이어가기, 결과 확인 및 계정 관리
- **관리자 화면:** 공고 생성·수정, AI 공고 자동 생성, 지원자 관리·비교, 다음 전형 대상자 및 통계 대시보드
- **기술 구현 검토:** 브라우저 지원 환경, 전체 화면 유지, 실시간 통신 및 브라우저 이동 제어
- **개발 연계 사항:** TRD 반영 대상 API·데이터 필드, 미결 사항 및 PRD 인수 기준 추적

### v0.3 주요 변경 사항

#### 1. 화면 접근 및 응시 상태 관리 강화

- 지원서 '작성 중' 상태와 관련 배지 및 화면 복귀 경로 보완
- 응시 상태에 따른 URL 직접 접근, 새로고침 및 재진입 처리 기준 구체화
- 지원 완료 후 마이페이지를 통한 응시 준비 재개 동선 정리
- 환경 점검 화면에 **[나중에 응시하기]** 버튼 추가

#### 2. 브라우저 및 지원 환경 정책 구체화

- 모바일·태블릿 미지원 정책 및 안내 화면 추가
- PC의 Chrome·Edge 지원 기준 명시
- 지원 절차, 응시 화면 및 관리자 화면에 대한 모바일 접근 제한 정의
- 모바일에서도 공고 탐색과 결과 확인은 가능하도록 화면별 접근 범위 구분

#### 3. AI 면접 및 코딩테스트 예외 처리 보완

- 동시 면접 상한을 AI 면접 단계에만 적용하도록 범위 명확화
- 코딩테스트 안내 단계는 동시 면접 상한에서 제외
- 장애 중단 시 코딩테스트 타이머 정지 및 재개 기준 구체화
- 화면 이탈 경고창 표시 중 재이탈하면 2회째 이탈로 처리하는 임시 규칙 추가
- 응시 중 브라우저 뒤로가기에 대한 History 제어 방안 및 기술 검증 사항 추가

#### 4. 공통 UI 및 관리자 기능 개선

- 데이터가 없는 목록·표·탭에 대한 빈 상태 표시 규칙 추가
- 분석 상태 용어를 '확인 필요'로 통일
- 게시 중인 채용공고의 수정 가능 항목 제한
- 게시 후 변경 사항을 공고 상세 화면에 날짜와 함께 표시하는 규칙 추가
- 마감된 공고의 수정 제한 기준 명확화

#### 5. 문서 및 기술 연계 사항 정비

- 기존 문서의 깨진 표 및 일부 표현 정리
- 화면별 상태와 버튼 동작의 일관성 보완
- 새롭게 정의된 화면 정책에 필요한 API·데이터 필드 정리
- PRD·TRD와의 정책 차이 및 추가 협의가 필요한 항목 갱신

### 문서 활용 방향

본 화면정의서는 프로젝트의 **공통 UI/UX 설계 및 화면 구현 기준 문서**로 활용합니다.

PRD의 기능 요구사항과 서비스 플로우차트의 사용자 흐름을 실제 화면 구성으로 연결하며, 프론트엔드 개발과 백엔드 API 연동 과정에서 참고 자료로 사용합니다.

각 팀원은 공통 화면정의서를 기반으로 개별적인 프로그램 구현을 진행하되, 화면별 필수 기능과 응시 상태 처리, 접근 권한 및 예외 상황에 대한 요구사항을 확인하여 핵심 기능이 누락되지 않도록 합니다.

특히 v0.3에서 구체화된 상태별 라우트 가드, 장애 복구, 타이머 제어 및 화면 이탈 처리 정책은 구현 방식에 따라 차이가 발생할 수 있으므로 개발 과정에서 검증이 필요합니다.

### 향후 검토 사항

현재 v0.3은 초안 단계이며, 일부 화면 정책과 기술적 가정에 대한 팀 검토가 필요합니다.

주요 검토 대상은 다음과 같습니다.

- 화면 이탈 경고 중 재이탈 처리 정책의 최종 확정
- 게시 후 공고 수정 가능 범위 및 변경 이력 관리 정책 확정
- 새롭게 추가된 API·데이터 필드의 TRD 반영
- PRD와 화면정의서 간 상태 및 정책 일치 여부 검토
- Next.js 환경에서 브라우저 뒤로가기 제어 및 응시 종료 감지 동작 검증
- 모바일 접근 제한 및 상태별 화면 전환 테스트

검토 결과는 관련 PRD·TRD·화면정의서에 반영하여 문서 간 일관성을 유지할 예정입니다.

※ 본 문서는 **v0.3 초안 기준**이며, 실제 개발 및 테스트 과정에서 화면 구성, 기술적 구현 방식과 세부 동작 정책이 변경될 수 있습니다.
