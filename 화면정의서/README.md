## 화면정의서 (Screen Specification)

**문서명:** AI 1차 채용면접 자동화 플랫폼 화면정의서  
**파일명:** `Final_Project_화면정의서_v0.2.md`  
**버전:** v0.2  
**최종 작성일:** 2026년 10월 28일  
**진행 상태:** 초안 (Draft) / 일부 화면 정책 및 기술 연계 사항 검토 필요  
**기준 문서:** 통합 PRD v1.3 · 서비스 플로우차트 07v · TRD v1.2

### 문서 개요

본 문서는 AI 기반 1차 채용면접 자동화 플랫폼의 사용자 및 관리자 화면 구성과 동작 방식을 정의한 문서입니다.

통합 PRD v1.3, 서비스 플로우차트 07v, TRD v1.2를 기반으로 각 기능을 실제 화면 단위로 구체화하였으며, 화면별 와이어프레임, 구성 요소, 버튼 동작, 화면 전환 조건, API 연계 및 예외 처리 방식을 정리하였습니다.

특히 지원자의 채용공고 탐색부터 지원서 제출, AI 면접, 코딩테스트, 결과 확인까지의 흐름과 관리자의 공고 관리 및 지원자 평가 업무를 구분하여 설계하였습니다.

이를 통해 **프론트엔드와 백엔드 개발 과정에서 발생할 수 있는 화면 구성 및 기능 해석의 차이를 최소화**하고, 공통된 구현 기준을 마련하는 것을 목적으로 합니다.

### 주요 작성 내용

- **화면 구조 및 정보 설계(IA):** 전체 사이트맵, 화면 ID, URL 라우트, 사용자별 접근 권한 정의
- **화면 전환 규칙:** 지원자·관리자별 화면 이동, 버튼 클릭, 자동 전환 조건 및 응시 상태별 화면 처리
- **공통 UI 규칙:** 레이아웃, 디자인 토큰, 버튼, 상태 배지, 알림, 모달 및 오류 처리 기준
- **인증 화면:** 로그인, 회원가입, 비밀번호 재설정 및 관리자 초기 비밀번호 변경
- **지원자 화면:** 공고 목록·상세, 필수 동의, 이력서 제출·수정, 환경 점검 및 면접 시작 안내
- **AI 면접 화면:** 질문 준비, 음성 질문·답변, 진행 상태 표시, 녹화 및 실시간 연결 상태 관리
- **코딩테스트 화면:** 시험 안내, 코드 작성, 자동 저장, 시간 관리 및 최종 제출
- **응시 예외 처리:** 네트워크 장애, 화면 이탈, 음성 인식 실패, 동시 면접 상한 초과 및 접수 마감 처리
- **마이페이지:** 지원 내역, 응시 상태, 면접 이어가기, 평가 결과 확인 및 계정 관리
- **관리자 화면:** 공고 생성·수정, AI 공고 자동 생성, 지원자 목록·상세, 지원자 비교, 다음 전형 대상자 및 통계 대시보드
- **기술 구현 검토:** 브라우저 환경, 전체 화면 유지, 실시간 통신 및 구현 시 예상 문제점과 대응 방안
- **개발 연계 사항:** TRD에 추가 반영할 API·데이터 필드, 미결 사항 및 PRD 인수 기준 추적

### v0.2 주요 변경 사항

- 통합 PRD v1.3 및 TRD v1.2의 요구사항과 기술 설계 반영
- 단일 관리자 계정 운영 방식에 맞춰 관리자 화면 구조 조정
- 이력서 OCR 지원 및 파일 업로드 정책 변경 사항 반영
- 비밀번호 생성·변경 규칙과 인증 화면 검증 기준 구체화
- 음성 인식 최종 실패 시 동일 질문 재답변 처리 방식 정의
- 접수 마감 시 진행 중인 면접도 즉시 종료하는 정책 반영
- 지원서 작성 중, 응시 준비 중, 장애 중단 등 상태별 복귀 경로 보완
- 코딩테스트 시작 안내 및 자동 전환 조건 추가
- 결과 화면의 채용 담당자 문의 이메일 안내 방식 정리
- 화면 구현에 필요한 API·필드와 기술적 미결 사항 별도 정리

### 문서 활용 방향

본 화면정의서는 프로젝트의 **공통 UI/UX 설계 및 화면 구현 기준 문서**로 활용합니다.

PRD에서 정의한 요구사항과 서비스 플로우차트의 흐름을 실제 화면 구성으로 연결하며, 프론트엔드 개발과 백엔드 API 연동 과정에서 참고 자료로 사용합니다.

각 팀원은 공통 화면정의서를 기반으로 개별적인 프로그램 구현을 진행하되, 화면별 필수 기능, 응시 상태 처리 및 사용자 흐름을 확인하여 핵심 요구사항이 누락되지 않도록 합니다.

또한 개발 과정에서 발견되는 화면 전환 오류, API 연동 문제, 사용자 경험상의 불편 사항을 검토하고, 필요한 경우 관련 문서와 함께 수정·보완할 예정입니다.

### 향후 검토 사항

현재 v0.2는 초안 단계로, 화면 구현을 위해 추가한 일부 가정과 미결 사항에 대한 팀 검토가 필요합니다.

특히 화면정의서에서 새롭게 도출된 API 및 데이터 필드는 TRD에 반영해야 하며, 문서 간 정책이 상충하는 항목은 팀 협의를 통해 최종 확정할 예정입니다.

※ 본 문서는 v0.2 초안 기준이며, 실제 개발 및 테스트 과정에서 화면 구성과 세부 동작 방식이 변경될 수 있습니다.
